CODE STRUCTURE

先分表面，再分组件。

三个平台共享 tokens.css 与 data.js；每个表面只拥有自己的外壳、布局和交互，不复制业务数据。

public/studio/ 
index.html          跨端主页（三个模块）
home.css / home.js  模块布局与平台切换
shared/
  tokens.css        Asana iOS token 映射
  data.js           GhollStudio 业务数据
mobile/
  index.html        iOS App 外壳
  app.css           列表 / 表单 / 标签栏
  app.js            状态机与交互
web/                （下一步）
desktop/            （下一步）
01数据只有一个来源

shared/data.js 暴露项目、工单、消息与通知；各端只读同一份结构。

02Token 只有一个来源

shared/tokens.css 管颜色、字阶、间距与圆角；深色模式只切变量。

03外壳各自独立

移动端用标签栏，桌面端用侧栏，网站用长滚动叙事；共享的是内容而不是布局。

04交互按端落地

移动端用底部 sheet、推送式聊天与顶栏创建入口；桌面端用表格、弹窗与快捷键。
