# 黄金样板间提示词（GOLDEN PROMPT）

> 本文件是整个项目的**唯一需求事实源**。所有约束写在这里，而不是代码里。
> 任何 code agent 拿到「本文 + 任一 designs/&lt;slug&gt;/DESIGN.md」，都应产出
> 一个同需求、不同人格的静态站点。需求一字不改，规范随意替换。

---

你是一名资深前端工程师兼品牌设计师。请严格依据下方需求与随附的 DESIGN.md 规范，
生成一个展示该设计规范全部性格的站点样板间。

## 一、产物契约（硬性）

1. 输出为**单个自包含的 `index.html`**（内联 CSS 与 JS；不引用任何网络字体、
   CDN、构建工具；允许 data URI；字体用规范声明的回退栈）。
   产物落点：`public/generated/<slug>/index.html`。
2. 双击即可在 `file://` 下完整运行；无后端、无外部请求。
3. 中文界面 + 品牌语境的可信样例数据。
4. 页面底部生成信息条：`由 AI agent 依 GOLDEN PROMPT + DESIGN.md「<规范名>」生成`。

## 二、规范消费（差异的来源，优先级高于你的默认审美）

- **Token 全部照搬**：把 DESIGN.md 的 YAML Token 逐值转成 CSS 自定义属性，
  页面样式只引用这些变量，禁止硬编码颜色/圆角/阴影/字体值。
- **components 指引**：规范中 `components.*`（button-primary 的圆角/底色/文字色、
  chips、inputs 等）决定对应组件的真实样式。
- **散文即指令**：规范 Overview/Elevation/Shapes/Do's and Don'ts 里每一句
  设计判断（例如「UI 退后，让产品说话」「阴影只出现在商品图上」「描边即层级」）
  都必须在页面上可见地执行。
- **指标决定气质**：Density/Variance/Motion 指标（无指标则依散文文气）控制
  留白节奏、版式不对称度与动效强度；Motion 为 0 时禁用全部 transition/animation。

## 三、站点结构（对所有规范一致）

真实品牌的第一舞台是**官网**，不是后台。站点含四个视图，
用符合品牌习惯的导航切换（客户端切换，无刷新）：

### 1. 品牌官网首页（主视图，篇幅最重）
- 品牌化导航（logo 字标 + 菜单 + 一个主 CTA）
- Hero：体现规范最高表达（大标题 + 副文 + 主/次动作 + 规范允许的第一屏视觉主体——
  产品窗格/图片磁贴/命令面板等，由规范气质决定）
- 信任行（客户 logo 墙或数据带）
- 特性区：3–6 项，版式随 Variance（网格或错落）
- 产品/场景展示区（图占位可用 CSS 绘制的抽象构图，禁止外链图）
- 客户评价 2–3 条
- 定价三档（含推荐态）
- FAQ 折叠 4 条
- 页脚（多列导航 + 订阅输入框）

### 2. 产品深页
- 一个具体能力/内容的深度呈现：长文编辑排版或产品功能分屏（左文右示意），
  含代码块/数据示意至少一种品牌化嵌入物

### 3. 应用后台（体现规范在密集 UI 下的状态，篇幅精简）
- KPI 3 卡；核心业务表 ≥8 行（语义状态徽章、右对齐数值、可排序至少一列）
- 一个高频表单条（输入/下拉/开关）；组件带：按钮全变体 + 徽章 + 空状态示例

### 4. 登录/注册
- 双 Tab 认证卡，输入焦点态与校验态符合规范

## 四、通用要求

- 键盘可达（Tab 顺序、焦点可见遵循规范 focus token）；对比度符合规范原则
- 响应式：≥1024px 完整；窄屏优雅折叠
- 完成后自查：代码顶部写「决策溯源注释」——每个关键界面决策来自规范的哪一行
