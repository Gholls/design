# DESIGN.md — Enterprise Admin

> 黄金样板间默认规范。为高密度数据后台设计：冷静、可预期、不抢内容。

## 设计理念

Enterprise Admin 是 design.gholl.com 的「基准线」规范。所有社区贡献的规范
都应在保持信息密度的前提下与本主题对比，验证自家 Token 是否真的可用。

- 主色是克制的云蓝（#2563eb），只用于可操作元素与焦点态。
- 表面分三层：`bg`（页面）、`surface`（卡片）、`surface-alt`（表头/输入底）。
- 阴影轻且冷，靠 1px 边框线 `border` 完成主要分隔。

## 配色

| Token | 色值 | 用途 |
| --- | --- | --- |
| primary | `#2563eb` | 主按钮、链接、选中态 |
| accent | `#7c3aed` | 次级强调、图表 |
| success / warning / danger | `#16a34a` `#d97706` `#dc2626` | 状态徽章 |
| text / muted | `#0f172a` `#64748b` | 正文 / 辅助文字 |

## 字体与排版

- 正文：Inter + 苹方回退，基准 15px，字距 -0.011em。
- 标题字重 600；不使用全大写。

## 形状语言

- 卡片圆角 12px，控件 8px，徽章全圆角（pill）。
- 边框统一 1px；阴影仅两级（card / control）。

## 密度

- spacing 缩放系数 1.0（标准密度）。
- 表格行高 44px —— 后台数据表的舒适下限。

## 适用场景

财务/订单/工单类管理后台；多状态数据表格；需要长时间阅读的场景。
