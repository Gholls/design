# DESIGN.md — Cyberpunk

> 夜之城控制台。光不是装饰，是信息的载体。

## 设计理念

反精致：拒绝圆角滑块与柔和投影，用 2px 直角、1px 描边和辉光阴影表达
「机器界面」的冷酷感。适合开发者工具、监控面板、Web3 场景。

- 深色底 `#0a0a12`，青 `#00f0ff` 为唯一主操作色，品红 `#ff2bd6` 只做稀缺强调。
- 强调态用「辉光」（box-shadow 扩散）而不是加深底色。

## 配色

| Token | 色值 | 用途 |
| --- | --- | --- |
| primary | `#00f0ff` | 主按钮（深色字保证对比度） |
| accent | `#ff2bd6` | 危险但迷人的强调 |
| success | `#2dff9e` | 在线 / 正常 |
| danger | `#ff3860` | 告警 |

## 字体与排版

- 全局等宽（JetBrains Mono 优先），基准 14px，字距 +0.04em。
- 数字天然对齐，适合终端式日志与指标。

## 形状语言

- 一切圆角 ≤ 2px；徽章也是方的。
- 卡片「描边即阴影」：`0 0 0 1px` + 环境辉光。

## 密度

- spacing 缩放 0.92，行高 40px —— 紧凑、克制、工程化。

## 适用场景

DevOps 面板、链上数据浏览器、游戏化后台。
