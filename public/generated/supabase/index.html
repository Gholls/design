实时订阅 postgres_changes

客户端直接监听数据库行事件，无需消息队列。realtime 通道继承 RLS 权限——用户只能收到自己可见的变更。

app/realtime.ts
const channel = client.channel('orders-feed')

channel.on('postgres_changes', {
  event: 'INSERT', schema: 'public', table: 'orders'
}, (payload) => renderRow(payload.new))

await channel.subscribe()  // 42ms 建连
